# Harry Potter Mobile Web RPG Draft

This repository contains the design draft for a mobile-first Harry Potter–style web RPG. You can preview the design in either Markdown or HTML form.

## Quick preview
1. Open `magic_world_design.html` in any modern browser for a styled preview, or view `magic_world_design.md` in your preferred Markdown viewer.
2. If you want to serve it locally, run:
   ```bash
   python -m http.server 8000
   ```
   then open [http://localhost:8000/magic_world_design.html](http://localhost:8000/magic_world_design.html).

## Files
- `magic_world_design.md`: Original design draft in Markdown.
- `magic_world_design.html`: Browser-ready preview of the draft with basic styling for mobile reading.
